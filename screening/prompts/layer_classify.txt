THE THREE LAYERS (where the general LLM / VLM sits relative to the robot's execution)

L1 准备层 (pre-execution / preparation). The agent works BEFORE the robot executes and prepares its world or its learning problem; its products are frozen before deployment and the LLM is not in the execution loop. Sub-types:
  环境/重建 = generates or reconstructs environments, scenes, simulation assets, digital twins (Real2Sim, scene generation);
  奖励/任务 = designs rewards, success checks, tasks, curricula, practice tasks (Eureka-style);
  本体/工具 = designs robot morphology, hardware or tools;
  系统/代码 = edits the training code, policy code base, skill library or harness and keeps / reverts changes by experiments (Developer-style, e.g. ENPIRE, PhysEvo).
L2 中间层 (harness: the LLM does NOT output low-level actions; a layer sits between it and the robot). Sub-types:
  策略生产者 = writes the policy as executable code / constraints / programs that then run on the robot (Code as Policies, ProgPrompt, VoxPoser, ReKep, CaP-X);
  编排者 = plans and calls skills, tools, motion planners or VLAs that do the actual control (SayCan, Inner Monologue, Harness VLA, Thea); VLN agents that pick sub-goals or waypoints for a local planner also go here; memory / lifelong agents go here when they act through skills;
  经验迁移 = the agent's experience, demonstrations or trajectories are distilled into a policy or a smaller model (SUDD, RoboTwin 2.0, GUAVA, CAPEX);
  运行时监控 = only intervenes on exceptions at runtime: failure detection, safety guardrails, recovery, asking for help (REFLECT, Code-as-Monitor, RoboGuard).
L3 执行层 (general LLM as policy during execution). The general model itself outputs the actions while the robot executes, with no skill library or policy program in between: joint commands, end-effector poses / waypoints / trajectories, discrete motion steps, or semantic micro-actions that directly specify the motion (e.g. "move 5 cm left"). Examples: GPT-6 Astra evaluated as a policy on RoboDojo, Prompt a Robot to Walk, VLMnav (VLM picks the next move each step).
